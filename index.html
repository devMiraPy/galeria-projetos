// linha do tempo

O Semestre em Código

Cada aula foi um commit. Aqui está o histórico do que aprendi.

01
Fundamentos

Introdução ao Desenvolvimento Web

Primeiro contato com a web como plataforma de desenvolvimento. Entendi a diferença entre front-end e back-end, como funciona o protocolo HTTP e por que o navegador é o ambiente de execução do HTML, CSS e JavaScript.

02
Estrutura

HTML Básico

Aprendi a anatomia de um documento HTML: tags, atributos, aninhamento e semântica. Conheci os elementos estruturais como <header>, <main>, <section> e <footer>.

03
Interação

Formulários HTML

Construí formulários acessíveis usando <input>, <label>, <select> e <textarea>. Entendi a importância dos atributos type, name e required para validação.

04
Visual

CSS Básico

Primeiras estilizações: cores, fontes, backgrounds e bordas. Entendi a cascata, a especificidade dos seletores e como o CSS é aplicado ao DOM. Consegui dar vida visual às minhas páginas pela primeira vez.

05
Layout

Box Model

Desmistifiquei o modelo de caixa do CSS: content, padding, border e margin. Aprendi a diferença entre box-sizing: content-box e border-box, o que mudou completamente meu controle de espaçamento.

06
Layout

Flexbox

Flexbox virou minha ferramenta principal para alinhamentos. Aprendi os eixos principal e cruzado, e propriedades como justify-content, align-items e flex-wrap, resolvendo layouts que antes pareciam impossíveis.

07
Layout

Grid Layout

Com Grid, passei a pensar em layouts bidimensionais. Aprendi a definir grid-template-columns, grid-template-rows, gap e posicionamento com grid-area, construindo estruturas de página completas com poucas linhas.

08
Responsivo

Responsividade

Entendi o conceito de design responsivo: que a página deve se adaptar ao dispositivo do usuário. Aprendi sobre viewport, unidades relativas como %, em, rem, vw e vh, e a lógica mobile-first.

09
Responsivo

Media Queries

Aprendi a usar @media para adaptar estilos a diferentes breakpoints. Implementei layouts distintos para desktop (acima de 1024px), tablet (768–1023px) e smartphone (até 767px), tornando minhas páginas funcionais em qualquer tela.

10
Animação

Animações CSS

Descobri o poder das transition e animation no CSS. Aprendi a criar micro-interações em hover, controlar duração, atraso e timing-function, dando feedback visual ao usuário sem uma linha de JavaScript.

11
Animação

Keyframes

Com @keyframes, passei a criar animações complexas com múltiplos estados. Aprendi a definir from/to e percentuais intermediários, criando efeitos como fade-in, slide, pulse e bounce — como os que estão nesta própria página.

12
Projeto

Projeto Integrador

A aula que fecha o ciclo. Reunindo tudo: HTML semântico, CSS avançado, responsividade, keyframes e boas práticas. O resultado é esta página — publicada no GitHub Pages e representando a jornada completa do semestre.
