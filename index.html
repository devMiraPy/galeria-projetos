// linha do tempo

O Semestre em Código

01
Hardware

Descobrindo o Computador

Primeiro mergulho na anatomia de uma máquina: processador, memória RAM, armazenamento e periféricos. Entendi como o hardware e o software se comunicam e por que essa base é essencial para qualquer profissional de tecnologia.

02
Sistemas

Explorando Sistemas Operacionais

Conheci as diferenças entre Windows, Linux e macOS — gerenciamento de processos, sistema de arquivos e permissões. Aprendi a usar o terminal como ferramenta de produtividade, não só como tela preta intimidadora.

03
Gestão

Metodologias Ágeis

Entendi a diferença entre Scrum e Kanban, o conceito de sprints, backlogs e daily meetings. Percebi que desenvolver software é tanto sobre pessoas e processos quanto sobre código — e que trabalhar em ciclos curtos entrega mais valor.

04
Identidade

Tipografia, Slogan e Arquétipo

Aprendi que uma marca vai muito além de um logo: ela tem voz, personalidade e propósito. Estudei hierarquia tipográfica, como construir um slogan que comunica valor e como os arquétipos de Jung se aplicam ao branding moderno.

05
Design

Prototipagem e Figma

Primeiro contato com o Figma: frames, componentes, auto-layout e prototipagem interativa. Aprendi a validar uma ideia visualmente antes de escrever uma linha de código — economizando tempo e retrabalho no desenvolvimento.

06
Experiência

Design UX e UI

Entendi a diferença entre UX (experiência do usuário) e UI (interface visual). Estudei heurísticas de Nielsen, fluxos de usuário, contraste de acessibilidade e como cada decisão visual impacta a usabilidade de um produto.

07
Estrutura

Primeira Página HTML

O momento em que o navegador abriu meu arquivo pela primeira vez. Aprendi a anatomia do documento: <!DOCTYPE>, <head>, <body>, tags semânticas e atributos. Ver "Olá, mundo" na tela mudou tudo.

08
Visual

Primeira Aula de CSS

Entendi a cascata, especificidade de seletores e o Box Model. Cores, fontes, espaçamentos — pela primeira vez uma página saiu do HTML puro e ganhou personalidade visual. Percebi que CSS é uma linguagem de design tanto quanto de código.

09
Versionamento

Git e GitHub

Aprendi os comandos essenciais: git init, add, commit, push e pull. Entendi o conceito de branches e merges. Publicar meu primeiro repositório no GitHub foi como lançar meu cartão de visitas para o mundo.

10
Equipe

Primeiro Projeto em Equipe

Trabalhar com mais pessoas no mesmo repositório trouxe desafios reais: conflitos de merge, pull requests e code review. Aprendi que colaborar em código exige tanto comunicação quanto habilidade técnica — e que o GitHub é o palco disso tudo.

11
Animação

Aula de Keyframes

Com @keyframes passei a criar animações com múltiplos estados — from/to e percentuais intermediários. Fade-in, slide, pulse, bounce: tudo sem JavaScript. Foi a aula que transformou páginas estáticas em experiências vivas.

12
Projeto

Media Queries e Projeto Final

A aula que fecha o ciclo. Aprendi a adaptar layouts com @media para desktop, tablet e mobile. O resultado é esta página — responsiva, animada, versionada no GitHub e representando tudo que conquistei no primeiro semestre.

De Zero ao Projeto

Meu início no curso

Quando comecei o curso ja tinha uma ideia do que ia estudar, já havia feito alguns projetos escolares que envolviam html e css, mas mesmo com essas experiencias o conhecimento era raso, e sentia muita dificuldade de enteder alguns conceitos sobre programação.

Mas estudando no senai consegui moldar muito melhor meus conceitos da programação.

  • Pouco contato com sistemas
  • Não sabia estruturar html e css
  • Não entendia conceitos de back e front end

Como estou agora

Hoje consigo estruturar uma página completa do zero, com HTML semântico e organizado. Sei a diferença entre cada elemento, como tornar uma página acessível com atributos ARIA, e por que semântica importa para SEO e leitores de tela.

No CSS, passei de "não sei como centralizar uma div" para criar layouts complexos com Flexbox e Grid, animações com @keyframes, variáveis CSS e interfaces responsivas.

  • HTML semântico com boas práticas de acessibilidade
  • CSS avançado: Flexbox, Grid, animações, variáveis
  • Layouts responsivos com Media Queries
  • Git e GitHub Pages para versionamento e deploy
  • Projeto integrador completo publicado online

Meu próximo objetivo

Entrar no mundo do JavaScript. Quero entender a lógica de programação de forma mais profunda — manipulação do DOM, eventos, funções, APIs e assincronismo.

Espero também estudar Python para garantir uma base sólida em lógica de programação, além de que Python é uma linguagem versátil e muito requisitada no mercado, o que pode abrir portas para diversas oportunidades. A longo prazo, essa base em Python pode facilitar a transição para outras linguagens e áreas, como desenvolvimento web, ciência de dados ou automação, ampliando ainda mais minhas possibilidades de carreira.

  • Aprender JavaScript e lógica de programação
  • Estudar Python e Moldar uma base sólida
  • Construir um portfólio com projetos reais
